## 真点操作脚本备忘（浏览器外）

1. `npm run build` → Chrome 加载 `.output/chrome-mv3`  
2. 另开终端：`node` 静态服 `scripts/p7c` 于 `8766`；`npm run laya:server` 于 `8765`  
3. 打开 `http://127.0.0.1:8766/`，侧栏探活 / 合并 / 执行，观察页内 log 与按钮点击计数  
4. 扩展点操作；页面用手点「提交投递」应仅人手触发
