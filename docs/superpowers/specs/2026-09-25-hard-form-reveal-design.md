# 难打开表单的扫描与写入

> 状态：待确认（2026-09-25）。确认后再改扫描与写入。

Boss 直聘在线简历、智联 / 猎聘编辑页、北森 / Moka / 米哈游一类网申，输入框经常不在页面上。要先悬停、点「编辑」、点页签，或点开下拉和日期，框才会出现。现在的扫描只点已经看得见的 `button` / 链接，所以这类页往往只剩一个已经摊开的输入框。

## 现在漏掉的原因

- 「编辑」常是 `span`、`div`、图标，不是 `button`。查询范围里没有它们。
- 悬停才出现的按钮是 `display: none` 或透明。`innerText` 对隐藏节点是空的，可见性判断也会把它丢掉。
- 样式上的 `:hover` 不能用假鼠标事件拨出来。靠脚本在 `mouseenter` 时才创建按钮的，不发移入事件就永远没有这个节点。
- 一块工具条里同时有「编辑」和「删除」。若按整段文字判断，会因为带「删除」而整条跳过。
- 点开后是弹层或抽屉，选项和下拉项这时才进 DOM。扫完不关掉，下一块就打不开。
- React / Ant Design / Element 的输入框是受控组件。只改 DOM 的 `value`，界面会弹回旧值。下拉和日期要先点开，再点中文选项。

## 点开顺序

每一块按这个顺序，命中就停，不再重复点：

1. 对卡片发 `mouseenter` / `mouseover`，等一小段，让脚本把按钮挂出来。
2. 在这块内部找「编辑」「修改」，含隐藏节点。用 `textContent`，不用 `innerText`。隐藏的先临时改成可见再点，点完不负责恢复样式，因为编辑层会接管这块。
3. 节点自己的文字必须就是编辑类。父级同时包着「删除」时，只点写着「编辑」的那个子节点。
4. 铅笔图标：`aria-label`、`title`、class 里的 edit / pencil，或旁边紧挨着的「编辑」二字。
5. 页签、折叠、`details`：文案像「基本信息」「工作经历」「教育经历」才点。点开后再在该页里找编辑。
6. 空区块的「添加 / 新增」只点一次。这块已经有经历卡片或输入框时不点。

不点：删除、保存、确定、提交、投递、下一步、上一步、发送、登录。会换网址的链接不点。

## 弹层

- 点编辑后等新的 `dialog`、抽屉、`.ant-modal`、`.el-dialog` 或就地出现的输入框。
- 新字段记下打开它的那个「编辑」。
- 扫完这一块，在弹层内部点「取消」「关闭」或右上角叉。不点「保存」「确定」。
- 若接着问「放弃修改吗」，只点「不保存」「放弃」「离开」。仍不点保存。
- 然后再打开下一块。Boss 直聘一次只开一个模块编辑，不收起就扫不到后面的经历。

写入时若框已经收起，再点当时记下的「编辑」，按标签把值填回去，仍然不保存、不提交。人在页面上自己看过再保存。

## 下拉、日期、富文本

这些框在编辑层打开之后才会出现，和「编辑」是两步。

- 原生 `select`：照现在按选项文字写入。
- Ant Design、Element 的选择器：先点输入框，等下拉层出现在 `body` 下，再点与档案一致的那一项文字。点不到就跳过该项，不乱选第一项。
- 日期：档案是 `YYYY-MM-DD`。页面只要年月时截成 `YYYY-MM`。能点开面板就点对应年月日；点不开就对输入框写入并派发 `input`、`change`、`blur`。React 受控框必须走这组事件，否则会弹回。
- 级联（城市、专业）：从左到右点每一列里匹配的文字。
- 富文本：写入 `contenteditable`，同样派发 `input`。
- 文件框：只填已经匹配好的附件，不在扫描时乱点上传。

米哈游一类日期面板对点击时序敏感。点开后面板没出来，就短等再点一次，仍没有就把该字段记为跳过。

## 其他情况

| 情况 | 做法 |
| --- | --- |
| 整页或内部区域要滚动才加载 | 继续滚最长的滚动区，直到滚不动 |
| 开放 Shadow DOM、同源 iframe | 继续进去扫 |
| 封闭 Shadow DOM、跨域 iframe | 扫不到。进度里说明这块进不去 |
| 虚拟列表，不在视口就没有节点 | 靠滚动扫，不靠一次查全页 |
| 按钮盖住、`pointer-events: none` | 不硬点。换这块里另一个写着「编辑」的节点 |
| 网站只认真人鼠标（`isTrusted`） | 程序点击无效。这块记入进度，其余块继续 |
| 画布、验证码、滑块 | 不处理 |
| 右键菜单 | 不打开 |
| 必须先填上一步才亮的按钮 | 不绕过禁用。禁用的编辑不点 |

## 上限与进度

- 编辑最多点 24 次，添加最多 8 次，页签最多 12 次。
- 整次扫描仍有时间上限。到点交回已经发现的输入框。
- 读条写清当前动作，例如「正在点开工作/实习经历的编辑，已发现 15 个输入框」。

## 不做

- 不自动保存、不自动提交、不点下一步。
- 不接入调试器去移动真实鼠标。那样浏览器会提示正在调试，不适合这个扩展。
