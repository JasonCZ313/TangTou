# 方案 B：侧边助手为主 + Popup 轻量加宽

> 状态：已确认并实现（2026-09-24）。  
> 日期：2026-09-24  
> 范围：**不**做网页悬浮球（方案 C 留作后续）。

---

## 1. 目标

解决 Popup「又小又挤、能力全堆在一起」的问题：

- **日常主力界面**改为 Edge/Chrome **Side Panel（侧边助手）**：选档案、扫描、预览映射、确认写入、撤销。
- **Popup** 变成「快捷条」：略加宽，只保留选档案、一键扫描、打开侧栏、打开设置；不再依赖小框做完整预览。
- 预览模式下点「扫描并填写」→ 生成计划后 **自动打开侧栏**（现有逻辑保留并强化文案）。

---

## 2. 角色分工

| 表面 | 职责 | 不做 |
|------|------|------|
| **Popup** | 选档案 / 设默认、扫描并填写、打开侧边助手、打开设置、快捷撤销 | 映射表编辑、长状态说明 |
| **Side Panel** | 档案选择、映射表核对与改值、确认写入、撤销、重新扫描、状态提示 | 档案 CRUD / API（仍在 Options） |
| **Options** | 档案编辑、API、填写模式 | 不变 |

`openPanelOnActionClick` 保持 `false`：点扩展图标仍开 Popup；侧栏由按钮或预览流程打开。

---

## 3. Popup 改动

### 3.1 尺寸与布局

- `body`：`min-width: 400px`，`max-width: 440px`（比现在 320–380 更长一点，仍符合扩展弹层习惯）。
- 操作区改为更清晰的纵向主次：
  1. 主按钮：**扫描并填写**（全宽）
  2. 次按钮一行两列：**打开侧边助手**（文案由「打开侧边栏」改为更贴切）｜**打开设置**
  3. 第三行：撤销本轮（ghost，全宽或次要样式）
- 无档案时：主按钮禁用；状态区明确引导点「打开设置」；可考虑主按钮旁弱提示（不强制改结构）。

### 3.2 文案

- 「打开侧边栏」→ **「打开侧边助手」**
- 就绪提示：强调「预览结果在侧边助手中确认」
- 预览成功：`已打开侧边助手，请核对后写入`

### 3.3 行为（基本沿用）

- `fillMode === 'preview'`：写 `pendingFillSession` → `OPEN_SIDE_PANEL`（已有）
- `fillMode === 'direct'`：Popup 内直接 APPLY，可不强制开侧栏
- 撤销仍可在 Popup 快捷执行（侧栏也保留撤销）

---

## 4. Side Panel 改动（助手化）

### 4.1 信息架构

自上而下：

1. **品牌头** + 短说明：「对照网页核对映射，确认后再写入」
2. **档案**下拉 + 链到 Options 的「管理档案」文字按钮（`chrome.runtime.openOptionsPage`）
3. **本页操作**：主按钮 **扫描本页**（现「重新扫描」升级为更显眼主操作之一）；有预览时 **确认写入** 为 primary
4. **映射表**（现有表格，可略增行高/字号便于阅读）
5. **撤销本轮** + 状态条

建议按钮层级（有预览时）：

- Primary：确认写入  
- Secondary：扫描本页  
- Ghost：撤销本轮  

无预览时 Primary 可为「扫描本页」。

### 4.2 空状态

无 `pendingFillSession` 时表格区文案改为：

> 尚未生成预览。可在此点击「扫描本页」，或从 Popup 点「扫描并填写」。

### 4.3 能力对齐（小幅）

- 侧栏已能选档案并重新扫描；保持与 Popup 同一套 Background 消息。
- 可选：侧栏增加「设为默认档案」勾选（与 Popup 一致）。**本期建议做**，减少必须回 Popup 的次数。

---

## 5. 非目标（本期不做）

- 网页内悬浮球 / content script FAB  
- 点击扩展图标直接打开 Side Panel（避免打破「先选档案再扫」的 Popup 习惯；若以后要做可单独开关）  
- 重做 Options / 品牌色体系  

---

## 6. 实现顺序

1. Popup：加宽 + 按钮排布 + 文案  
2. Side Panel：空状态、按钮层级、「管理档案」、可选默认档案勾选  
3. 手测：无档案 → 开设置；有档案 → Popup 扫描 → 侧栏预览写入；侧栏内单独扫描  

---

## 7. 验收

- [ ] Popup 视觉明显更宽（≥400px），主次按钮不挤成一团  
- [ ] 默认预览模式下，扫描后侧栏自动打开且能看到映射表  
- [ ] 仅用侧栏也能完成：选档案 → 扫描 → 确认写入 → 撤销  
- [ ] 「打开设置」仍进 Options；民族/省市区等档案编辑不受影响
