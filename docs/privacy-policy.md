# 躺投（TangTou）隐私政策

**生效日期：** 2026-10-01  
**适用产品：** 浏览器扩展「躺投」

本文说明躺投如何处理数据，供用户阅读及 Chrome / Edge 应用商店上架披露使用。

## 1. 我们是谁

躺投是一款在浏览器本机运行的简历档案与表单辅助填写扩展。开发者不运营用于收集档案或 API Key 的自建服务器。

## 2. 单一用途

本扩展的用途是：在用户本机维护简历档案，并在用户确认后，辅助将档案内容映射填写到用户正在浏览的网页表单。扩展**不会**自动提交或投递表单。

## 3. 数据存储位置

| 数据类型 | 存储位置 | 是否离开本机 |
|----------|----------|--------------|
| 简历档案、附件元数据 | 浏览器 `chrome.storage` / IndexedDB | 默认否 |
| API Key、Base URL、模型名 | 浏览器本机设置 | 否（仅你配置的 API 域名在请求时使用 Key） |
| 填写预览会话 | `chrome.storage.session` | 否 |
| 本机 Laya 判断包缓存 | IndexedDB | 否 |
| Token 用量统计 | 本机存储 | 否 |

导出 JSON 时**强制剔除** API Key。

## 4. 网络传输（仅发往你配置的地址）

当使用云端映射、润色、探活方案等功能时，扩展会把**表单字段摘要、档案相关字段、可选的可见区截图（多模态）**发送到你在设置中填写的 **API Base URL**（OpenAI 兼容服务商或本机 Ollama）。

- 开发者**不接收**这些请求内容。  
- 数据如何被服务商处理，以该服务商的隐私政策为准。  
- 你可以不配置 API，仅使用本机规则 / 内置轻量判断（能力会降级）。

## 5. 截图与 OCR

为辅助识别弱标签字段或智能探活，扩展可能对**当前活动标签的可见区域**截图，并在**本机**用 Tesseract 做 OCR。

- 截图默认用于本机识字；若你开启云端探活且模型支持，可能把压缩后的可见区截图一并发给你配置的 API（失败则回退纯文本）。  
- 截图**不会**上传到开发者服务器。  
- 截图可能包含页面上可见的个人信息，请仅在你信任的页面与 API 服务商下使用。

## 6. 受控探测点击

「智能探活」可在预算内点击打开下拉/展开面板以读取选项，用于生成方案。

- **不会**点击提交、投递、保存类按钮。  
- **不会**在探测阶段点击「添加行」类按钮。  
- 真正写入仍须你在侧栏确认。

## 7. 本机模型缓存

若启用本机 Laya（内置轻量包或自行下载的包）：

- 模型文件缓存在本机 IndexedDB（`unlimitedStorage`）。  
- 商店安装包**不包含**大型专用模型权重；ORT WASM 运行时仅为可选推理脚手架，失败时回退轻量判断或云端。

## 8. 权限与目的

扩展申请的权限仅用于上述用途，详见商店上架说明与 README「权限说明」。我们不会将权限用于广告追踪或向第三方出售数据。

## 9. 用户控制

- 可随时在浏览器中清除扩展数据、卸载扩展。  
- 可在设置中更换或删除 API Key。  
- 可关闭本机 Laya、不使用探活/多模态。  
- 写入前可在侧栏改值或取消。

## 10. 儿童与敏感数据

本产品面向求职成年人。请勿在档案中存放与求职无关的敏感证件扫描件（除非你明确需要且了解将发往自己的 API）。

## 11. 政策变更

若数据处理方式发生实质性变化，我们将更新本文档与扩展内提示，并在应用商店列出新版本说明。建议你在重大更新后再次阅读本政策。
