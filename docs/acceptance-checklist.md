## 建议冒烟步骤（手动）

1. `npm install` → `npm run build`（及可选 `npm run build:edge`）。
2. Edge / Chrome 加载对应 `.output/*-mv3` 目录。
3. Options：配置 Base URL / Key / 模型；创建、改名、复制档案至 5 份上限。
4. 打开本地静态 HTML 表单页：预览填写 → 确认写入 → 撤销；再测直接填写。
5. 导出 JSON，确认默认无 `apiKey`。
6. 可选：1～2 个真实招聘站仅做扫描与填写冒烟（勿自动提交）。

勾选完成后，可将上表「待手动」改为「已完成」，并同步更新设计规格 §13 中的复选框。
